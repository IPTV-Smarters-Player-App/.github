## Overview
As an iptv smarters player, this app exists to organize IPTV subscriptions and M3U playlists people already own rather than to supply any content of its own. IPTV Smarters Player for Windows takes that existing playlist or Xtream Codes login and turns it into a clean channel list, complete with a program guide, favorites, and multi-screen viewing where supported.

## Features

## Getting Started
Right after installing, IPTV Smarters Player asks how you'd like to connect: an M3U link, an M3U file already on your PC, or an Xtream Codes login. Enter the details for the service you already use, let the channel list populate, then spend a few minutes marking favorites and checking the program guide before settling in to watch.
